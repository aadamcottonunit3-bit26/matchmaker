URDU FONT (Jameel Noori Nastaleeq)
==================================
The website uses "Jameel Noori Nastaleeq" for all Urdu text.

To use it for every visitor, put the font file here with EXACTLY this name:

    public/fonts/JameelNooriNastaleeq.ttf

(If your copy is named "Jameel Noori Nastaleeq.ttf", just rename it.)
Then push to GitHub; Vercel will redeploy.

Until that file is added, visitors see the bundled "Noto Nastaliq Urdu"
(NotoNastaliqUrdu-OFL-LICENSE.txt), which is also Nastaliq style. Visitors who
already have Jameel Noori Nastaleeq installed on their device see it automatically.

Please make sure you have the right to publish the font file you add.
